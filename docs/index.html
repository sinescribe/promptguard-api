Quick Install & Production API

      
pip install promptguard-api
promptguard-api

      
curl -X POST http://127.0.0.1:8000/v1/scan \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_GUMROAD_LICENSE_KEY" \
  -d '{"prompt": "__import__(\"os\").system(\"whoami\")", "strict_mode": true}'

      
HTTP server requires fastapi, uvicorn, and pydantic; core analyze_prompt() uses only Python stdlib. VALID_API_KEYS starts empty by default — configure PROMPTGUARD_API_KEYS or validate live Gumroad Pro license keys via X-API-Key against /v1/scan and /v1/batch-scan.
